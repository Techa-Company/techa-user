````markdown
## 🧰 راه‌اندازی پروژه

1. کلون کردن ریپازیتوری:
   ```bash
   git clone https://github.com/Ramin-Joshang/techa-user.git
   ```
````

2. نصب دپندنسی‌ها:

   ```bash
   npm install
   # یا
   yarn install
   ```

3. اجرای محیط توسعه:
   ```bash
   npm run dev
   # یا
   yarn dev
   ```

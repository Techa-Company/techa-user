## 🚀 راه‌اندازی

1. کلون پروژه:
   ```bash
   git clone https://github.com/Ramin-Joshang/techa-user.git
   ```
````

2. نصب دپندنسی‌ها:
   ```bash
   npm install
   ```
3. اجرای لوکال:
   ```bash
   npm run dev
   ```

---

## 📝 مشارکت

1. ریپو را **Fork** کنید
2. برنچ جدید بسازید:
   ```bash
   git checkout -b feature/feature-name
   ```
3. کامیت تغییرات:
   ```bash
   git commit -m 'feat: افزودن قابلیت جدید'
   ```
4. ارسال PR به برنچ اصلی
